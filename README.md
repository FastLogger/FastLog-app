# FastLog – Pilotenlogbuch für Android

Persönliches Logbuch im Format AMC1 FCL.050 (EASA). Schnelle Eingabe von Flügen und Simulator-Sitzungen,
Import des Airline-Logbuchs (Excel), Export als PDF-Logbuch, Excel und CSV. Alle Zeiten in UTC.

## Installieren

1. Auf dem Android-Handy diesen Link öffnen und die Datei herunterladen:
   **[FastLog.apk herunterladen](https://raw.githubusercontent.com/FastLogger/FastLog-app/main/FastLog.apk)**
2. Die heruntergeladene Datei öffnen. Android fragt, ob der Browser Apps installieren darf: einmal erlauben.
3. «Installieren» tippen. Warnt Google Play Protect vor einer unbekannten App: «Weitere Details» →
   «Trotzdem installieren» (oder den angebotenen Scan durchführen). Das ist bei Apps ausserhalb des
   Play Store normal.

## Updates

FastLog prüft beim Start einmal pro Tag, ob es eine neue Version gibt, und zeigt dann oben einen Hinweis.
Antippen lädt die neue Version und öffnet das Installationsfenster von Android. Deine Einträge bleiben
erhalten. Von Hand: *Setup → About → Check for updates*.

## Deine Daten

- Das Logbuch ist nur auf deinem Handy gespeichert. Nichts wird an einen Server gesendet.
- Android sichert es mit dem normalen Handy-Backup in dein Google-Konto, wenn das Backup eingeschaltet ist.
- **Speichere regelmässig eine Sicherungsdatei** (*Setup → Data → Save backup file*), z.B. in Google Drive,
  und exportiere ab und zu ein PDF.

## Wichtig

FastLog ist ein privates Projekt ohne Gewähr. Du bist selbst für die Richtigkeit deines Logbuchs
verantwortlich: Prüfe importierte und berechnete Werte (z.B. Nachtzeit) und vergleiche die Totale mit den
Angaben deiner Airline.

Datenquellen: OurAirports (Public Domain), mwgg/Airports (MIT), Natural Earth (Public Domain).
